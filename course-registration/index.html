학교마다 접수 방식과 조건이 다릅니다. 아래는 일반적인 점검 순서이며, 실제 일정·대상·절차는 학교가 제공하는 공지를 확인해야 합니다.

TIME AS A REFERENCE

수강신청 서버시간은 어떻게 참고하나요?

동클 Basic은 무료 Windows PC 앱입니다. 학교가 안내한 공식 신청 페이지의 HTTP 또는 HTTPS 주소를 복사해 앱에 넣고 측정을 시작합니다. 주소 입력부터 측정 상태 확인까지는 사용 가이드에서 확인할 수 있습니다.

공식 공지 우선
신청 시작·종료 시각과 운영 규칙은 학교의 공식 안내를 기준으로 확인하세요. 이 페이지는 특정 학교의 일정이나 호환성을 안내하지 않습니다.
관측 대상의 차이
학교 홈페이지, 로그인 페이지, 실제 수강신청 처리 서버가 다를 수 있습니다. CDN이나 캐시의 HTTP Date가 내부 접수 시계와 같다고 보장할 수 없습니다.
밀리초의 의미
HTTP Date는 일반적으로 1초 해상도입니다. 앱 화면의 밀리초와 예상오차는 관측에 따른 추정이며, 고정 정확도나 신청 성공을 뜻하지 않습니다.

동클은 서버시간을 추정해 표시하는 도구입니다. 자동 클릭·자동 수강신청 기능은 제공하지 않으며 신청 성공을 보장하지 않습니다. 정확도 및 한계 →

COMMON QUESTIONS

자주 묻는 질문

학교 이름이나 수강신청 주소가 목록에 없으면 쓸 수 없나요?

이 페이지는 학교별 지원 목록을 제공하지 않습니다. 앱에서 대상 HTTP 또는 HTTPS 주소를 입력할 수 있지만, 측정 가능 여부는 실제 응답과 네트워크 조건에 따라 달라집니다.

신청 버튼은 정확히 언제 눌러야 하나요?

서비스의 내부 접수 판정 시각과 HTTP 응답 시각이 같다고 보장할 수 없어 특정 선클릭 시점을 안내할 수 없습니다. 학교의 공식 시각과 화면 안내를 따르고 시간 표시는 참고 자료로 사용하세요.

상황에 맞게 이어서 확인하세요

서버시간 확인 →HTTP Date와 예상오차를 이해하고 관측 조건을 정리하세요.티켓팅 준비 →공식 오픈 안내부터 인증·선택·완료 내역까지 점검하세요.
