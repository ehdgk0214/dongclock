시계 세 가지를 먼저 구분하세요

“서버시간이 다르다”는 말은 서로 다른 기준을 비교한 결과일 수 있습니다. 무엇을 읽었는지부터 확인하면 숫자를 해석하기 쉬워집니다.

  1. 내 PC 시계

    운영체제가 표시하는 현재 시각입니다. PC에서 보이는 시계와 웹사이트 응답의 시각은 어긋날 수 있습니다.

  2. 웹 응답의 시각

    동클은 대상 URL의 HTTP 응답에서 얻은 Date와 왕복 시간을 이용해 시간을 추정합니다. 응답 경로에 따라 관측 대상이 달라질 수 있습니다.

  3. 실제 접수 판정 시각

    신청·예약을 처리하는 내부 서버가 별도로 있을 수 있습니다. 웹 응답의 Date가 내부 접수 기준과 같다고 단정할 수 없습니다.

밀리초까지 보이면, 밀리초까지 정확할까요?

표시의 자릿수와 실제 정확도는 다릅니다. HTTP Date는 일반적으로 1초 해상도이며, 동클 화면의 밀리초는 여러 관측과 시계 진행을 바탕으로 만든 추정 표시입니다.

예상오차
앱이 관측한 표본과 지연에 근거한 제품 지표입니다. UTC 기준 정확도나 신청 성공 확률을 증명하지 않습니다.
CDN·캐시
응답이 캐시나 중간 서버에서 만들어질 수 있습니다. 측정한 Date가 서비스 내부 서버의 현재 시각과 같다고 보장할 수 없습니다.
네트워크 지연
왕복 시간은 관측할 수 있지만 두 방향의 편도 지연을 각각 알 수는 없습니다. 왕복 시간의 절반이 정확한 편도 지연이라는 보장도 없습니다.

고정된 밀리초 정확도는 보장하지 않습니다. 관측 범위를 자세히 알고 싶다면 정확도 및 한계를 확인하세요.

COMMON QUESTIONS

자주 묻는 질문

브라우저에서 바로 서버시간을 측정하나요?

이 페이지는 설명과 준비 도구를 제공합니다. 실제 측정은 Windows PC용 DongClock Basic에서 대상 주소를 입력해 시작합니다.

측정이 안 되거나 값이 흔들리면 어떻게 하나요?

입력 주소와 네트워크 연결을 확인하고 앱의 상태를 읽으세요. 응답과 네트워크 조건에 따라 측정 가능 여부가 달라집니다. 사이트의 차단·제한 안내가 있으면 이용 규칙을 따르세요.

상황에 맞게 이어서 확인하세요

수강신청 준비 →과목 코드·분반·대안을 정리하고 신청 내역까지 확인하세요.티켓팅 준비 →공식 오픈 안내부터 인증·선택·완료 내역까지 점검하세요.
