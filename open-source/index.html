오픈소스 및 제3자 라이선스

DongClock Server Time Basic과 Pro는 Rust, Tauri 및 기타 오픈소스 구성요소와 IBM Plex Sans 폰트를 사용합니다.

1. 전체 고지

구성요소명, 정확한 버전, 라이선스 식별자, upstream 및 source URL, 저작권·NOTICE와 라이선스 전문은 THIRD-PARTY-NOTICES.txt에서 확인할 수 있습니다. 동일한 파일은 앱의 Portable 배포 폴더 및 Installer 설치 디렉터리에도 제공됩니다.

2. MPL-2.0 소스 제공

DongClock은 MPL이 적용되는 제3자 소스를 직접 수정하지 않았습니다.

정확한 버전별 Source Code Form: cssparser 0.36.0, cssparser-macros 0.6.1 (build-time), dtoa-short 0.3.5, option-ext 0.2.0, selectors 0.36.1. DongClock 고유 소스에 MPL이 확대 적용된다는 뜻은 아닙니다.

3. IBM Plex Sans

앱에 포함된 IBM Plex Sans Medium/SemiBold Latin1 폰트는 SIL Open Font License 1.1로 제공됩니다. Copyright © 2017 IBM Corp. with Reserved Font Name “Plex”. OFL 전문은 전체 고지에 포함되어 있습니다.

4. 라이선스 범주

현재 Windows x64 production graph에는 MIT, Apache-2.0, BSD, ISC, Zlib, Unicode-3.0, CC0, Unlicense, MPL-2.0, OFL-1.1 및 그 밖의 permissive license가 포함됩니다. 잠긴 production graph의 metadata에서 GPL, LGPL 또는 AGPL은 발견되지 않았습니다.
