DONGCLOCK BASIC GUIDE

How to measure
website server time

Copy the address of the website you want to check, paste it into DongClock Basic, and start a measurement. The screenshots below follow the actual workflow from opening the website to completing a measurement session.

Download Basic Back to homepage
8 STEPS
  1. Open the website you want to measure
  2. Check the URL in the address bar
  3. Copy the website address
  4. Paste the address into DongClock
  5. Start measurement
  6. Check the initial measurement state
  7. Watch the measurement status and estimated error
  8. Finish or start a new measurement
01

Open the website you want to measure.

Open the website whose server time you want to check. This can be a ticketing site, course-registration page, reservation service, or another time-sensitive website.

02

Check the URL in the address bar.

The HTTP or HTTPS address shown in the browser address bar is the target you will give to DongClock.

03

Copy the website address.

Select the full URL in the address bar and copy it. DongClock can use that address directly in the server-address field.

04

Paste the address into DongClock.

Open DongClock Basic and paste the copied URL into the server-address field. You can also type the address manually.

05

Select Start Measurement.

After checking the address, select Start Measurement. DongClock begins observing the website's HTTP responses and network round-trip timing.

06

Let the initial measurement settle.

DongClock first gathers multiple observations and updates its server-time estimate and estimated error. It is better to watch the measurement for a while rather than rely on the first displayed value.

07

Check the status and estimated error.

While measurement continues, you can monitor the displayed server time, current state, and estimated error. Values may continue to adjust depending on network conditions and the target server's response behavior.

08

Start a new session when needed.

When the Basic measurement session ends, review the final state. Select Measure Again if you want to start a fresh measurement session.

Good to know

DongClock measures and displays server time. It does not automate clicks, registrations, reservations, or purchases. Because HTTP Date has limited resolution and network delay cannot be observed perfectly, the displayed milliseconds are an estimate derived from multiple observations rather than millisecond precision directly supplied by the server.
